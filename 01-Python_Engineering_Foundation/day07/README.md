# Student Score Utility

A small Python project that calculates the average of student scores.

## Features

- Calculates the average score.
- Rejects empty score lists.
- Validates numeric inputs.
- Handles invalid input with clear errors.
- Includes automated unit tests.

## Project Structure

- `student_scores.py` - Average calculation and validation.
- `main.py` - Runs the application.
- `test_student_scores.py` - Automated unit tests.

## Requirements

- Python 3.10 or newer
- No third-party packages required

## Run the Application

```powershell
python main.py
```

## Run the Tests

```powershell
python -m unittest -v
```
