# AI Engineer Roadmap — Locked Weekly Study Plan

**Timeline:** October 16–December 31, 2026  
**Daily study target:** 3–4 focused hours, six days a week, with one lighter revision day.  

---

## Week 1 · October 16–22 — Python Programming and Problem-Solving

- Functions, loops, lists, dictionaries, sets, and strings
- OOP, classes, inheritance, exceptions, and file handling
- Modules, virtual environments, Git, and GitHub
- Solve 2–3 Python problems daily

## Week 2 · October 23–29 — APIs, SQL, and ML Foundations

- Build REST APIs with FastAPI and understand HTTP/JSON
- SQL `SELECT`, `JOIN`, `GROUP BY`, and subqueries
- NumPy, Pandas, and data preprocessing
- Train your first regression and classification models

## Week 3 · October 30–November 5 — Machine Learning and Evaluation

- Train/test split, cross-validation, and data leakage
- Linear/logistic regression, trees, and random forests
- Precision, recall, F1, ROC-AUC, and confusion matrix
- Build and document an end-to-end ML pipeline

## Week 4 · November 6–12 — Deep Learning and NLP

- Tensors and Neural Networks

## Week 5 · November 13–19 — LLM Application Development

- LLM APIs, prompts, and structured JSON output
- Context windows, tokens, temperature, and streaming
- Function calling, retries, error handling, and validation
- Build a small AI assistant with a Python API

## Week 6 · November 20–26 — RAG and Semantic Search

- Document loading, chunking, and embeddings
- Vector search, metadata filters, and retrieval
- Build a document question-answering application
- Evaluate retrieval quality and reduce unsupported answers

## Week 7 · November 27–December 3 — AI Agents and Application Design

- Tool calling and controlled multi-step workflows
- State, tool outputs, timeouts, and failure handling
- Build one simple tool-using assistant
- Learn when a normal workflow is better than an agent

## Week 8 · December 4–10 — Deployment and Production Quality

- FastAPI validation, testing, and API documentation
- Docker, environment variables, and secret management
- Logging, latency, cost, rate limits, and basic monitoring
- Deploy an application and test it outside your notebook

## Week 9 · December 11–17 — Portfolio Project 1

- Build a complete RAG document assistant
- Add citations to retrieved source passages
- Create a clean UI or API, tests, and README
- Record a demo and document limitations

## Week 10 · December 18–24 — Portfolio Project 2

- Build an AI support-ticket assistant or intelligent search tool
- Add structured outputs and a useful real-world workflow
- Evaluate with a small test set and handle failure cases
- Publish code, setup instructions, and a demo

## Week 11 · December 25–31 — Interview Preparation and Job Applications

- Revise Python, SQL, ML, LLM, and RAG concepts
- Practice coding problems and explain your architecture
- Update resume, portfolio, GitHub, and LinkedIn
- Apply to suitable AI Engineer and GenAI Engineer roles

---

## Progress-tracking rule

Treat this as the locked weekly plan. Follow the weeks in order, verify each practical checkpoint before advancing, and record completed work in the project repository. Do not silently skip topics or replace the roadmap with a different plan.
